# Generated Word Datasets

The following files are generated by:

```bash
cd backend
python manage.py generate_words_dataset
```

Expected generated files:

- `uzbek_words.json`
- `turkish_words.json`
- `kazakh_words.json`
- `kyrgyz_words.json`
- `azerbaijani_words.json`
- `turkmen_words.json`
- `old_turkic_words.json`

The default command target is 60,000 total records.
