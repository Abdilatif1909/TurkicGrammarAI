# TurkicGrammarAI

Cognate-aware multilingual embedding framework for Turkic lexical resources.

Status: **in progress**

Current completed stage:

- [Bosqich 0 - Data audit](docs/data_audit.md): 7 language files found, 7,844 total records, shared flat schema, and no within-file duplicate word forms.

Bosqich 1 adds the project skeleton, raw data copy under `data/raw/`, and a dynamic JSON loader for all available `*_words.json` files.
