# Threats to Validity

## Internal Validity

- Several benchmarks are generated by repository scripts from the same resources used to build the embedding dataset, which can create circularity between training resources and evaluation resources.
- Some benchmark cases are synthetic or semi-synthetic. The measured metrics are internally reproducible but may overestimate performance on independently curated linguistic data.
- FastText evaluation uses generated distractors and stored benchmark pairs; ranking difficulty depends on this construction.
- The current package does not include controlled retraining ablations, so feature contribution claims must remain cautious.

## External Validity

- Results may not generalize to unseen Turkic corpora, dialectal data, noisy OCR, social media text, or expert-curated lexica outside the repository.
- Uyghur Arabic-script and Old Turkic runiform support exists in the dataset, but external coverage and normalization quality still require specialist review.
- The evaluation does not establish performance against widely accepted external multilingual embedding benchmarks.

## Construct Validity

- Cognate-aware similarity, semantic retrieval, historical relatedness, and morphology-aware retrieval are related but distinct constructs. High retrieval metrics should not be interpreted as full linguistic correctness.
- Positive/negative similarity means summarize broad pair groups and do not prove clean cluster separation; stored cluster metrics include negative separation for some cluster types.
- QA accuracy measures whether expected words appear in structured answers, not whether the answer is complete, explanatory, or publication-grade linguistically.

## Dataset Validity

- Provenance metadata is incomplete for some generated or merged lexical records.
- The embedding dataset intentionally merges words, morphology benchmarks, historical forms, corpus hooks, lemma dictionaries, and cognates; this helps coverage but increases leakage risk.
- Lemma/root quality is only as reliable as the source data and generation rules used to construct each record.

## Benchmark Validity

- Benchmark generation scripts create evaluation cases from the same semantic index or embedding dataset, so benchmark leakage is plausible.
- Negative pairs are sampled and may not always represent difficult semantic negatives.
- Cross-language cases depend on cognate grouping and may underrepresent non-cognate translation equivalence.

## Reproducibility Threats

- Current validation traces stored artifacts; it does not rerun training or regenerate metrics.
- FastText training may vary with library version, worker count, random state, and corpus ordering if rerun.
- Raw similarity distributions are not stored, limiting reproducibility of effect-size calculations.

## Publication Risks

- Claims of state-of-the-art, production readiness, human-level performance, or Q1 readiness are not supported by current validation evidence.
- Baseline and controlled ablation results are absent; reviewers may require these before accepting strong contribution claims.
- External expert validation and independently curated gold datasets remain the largest scientific blockers.
